# QR Code 생성기

순수 HTML / CSS / JavaScript로 만든, 브라우저에서 바로 동작하는 QR 코드 생성기입니다.
서버나 빌드 과정 없이 `index.html`을 열기만 하면 동작하며, [qr-code-styling](https://github.com/kozakdenys/qr-code-styling) 라이브러리(MIT License)를 기반으로 합니다.

---

## 1. 한눈에 보는 기능

- **9가지 QR 종류 지원**: 텍스트 / 와이파이 / URL / 이메일 / 전화(전화) / 전화(문자) / 연락처 / 일정 / 위치
- **휴대폰 카메라 자동 인식 형식**으로 데이터 생성 (와이파이 자동 연결, 이메일 앱 실행 등)
- **디자인 커스터마이징**: 색상, 그라데이션, 모양, 로고 삽입, 오류 복원율 등 세부 조정
- **스타일 저장/불러오기**: 자주 쓰는 디자인을 이름 붙여 저장 후 재사용
- **히스토리(생성 기록)**: 만든 QR 목록 확인, 다시 불러오기, 개인정보 보호 설정 포함
- **반응형 디자인**: 모바일은 1열, 데스크톱(900px 이상)은 3단 사이드바 레이아웃
- **한글 깨짐 수정**: UTF-8 바이트 변환 처리로 한글 QR도 정상 스캔
- **모든 데이터는 로컬에만 저장**: 서버로 전송되지 않고 브라우저 `localStorage`에만 보관

## 2. QR 종류별 상세 설명

| 종류           | 휴대폰에서 인식 시 동작                    | 입력 항목                                       |
| -------------- | ------------------------------------------ | ----------------------------------------------- |
| 텍스트         | 텍스트 그대로 표시                         | 텍스트                                          |
| 와이파이       | 비밀번호 입력 없이 자동 연결               | SSID, 비밀번호, 암호화 방식, 숨김 네트워크 여부 |
| URL            | 브라우저로 해당 주소 열기                  | URL (프로토콜 생략 시 `https://` 자동 추가)     |
| 이메일         | 메일 앱 실행, 받는사람/제목/내용 자동 입력 | 받는 사람, 제목(선택), 내용(선택)               |
| 전화번호(전화) | 전화 앱에서 발신 화면으로 이동             | 전화번호                                        |
| 전화번호(문자) | 문자 앱에서 작성 화면으로 이동             | 전화번호, 문자 내용(선택)                       |
| 연락처         | 연락처 추가 화면으로 이동 (vCard)          | 이름, 전화번호(선택), 이메일(선택), 회사(선택)  |
| 일정           | 캘린더 앱에서 일정 추가 (iCalendar)        | 제목, 시작/종료 일시, 장소(선택), 설명(선택)    |
| 위치           | 지도 앱에서 해당 좌표 열기                 | 위도, 경도                                      |

내부적으로 각 종류는 표준 형식(`WIFI:`, `mailto:`, `tel:`, `sms:`, `BEGIN:VCARD`, `BEGIN:VEVENT`, `geo:` 등)으로 인코딩되며, 특수문자(`;`, `,`, `:`, `\`)는 스펙에 맞게 자동으로 escape 처리됩니다.

## 3. 디자인 설정

| 카테고리             | 조정 가능한 항목                                                  |
| -------------------- | ----------------------------------------------------------------- |
| 스타일 저장/불러오기 | 현재 디자인을 이름으로 저장, 불러오기, 삭제                       |
| 기본 설정            | 모양(사각형/원형), 너비/높이(px), 전체 여백, 오류 복원율(L/M/Q/H) |
| 로고 이미지          | 로고 URL, 크기(0~0.5), 마진                                       |
| 도트(점) 스타일      | 색상, 단색/그라데이션, 모양(사각형/둥근 사각형/점 패턴/클래식 등) |
| 배경 스타일          | 색상, 단색/그라데이션                                             |
| 모서리 사각형 스타일 | 색상, 그라데이션, 모양 (비워두면 도트 스타일을 따라감)            |
| 모서리 도트 스타일   | 색상, 그라데이션, 모양 (비워두면 도트 스타일을 따라감)            |

세부 카테고리는 아코디언으로 접혀 있으며, **한 번에 하나만 펼쳐지는 방식**입니다.

## 4. 히스토리(생성 기록) & 개인정보 보호

QR을 생성할 때마다 종류, 입력했던 값, 디자인 설정이 기록에 남습니다. 단, **개인정보 보호를 위해 아래 항목은 기본적으로 기록되지 않습니다**(설정에서 개별적으로 켤 수 있음):

- 와이파이 비밀번호
- 연락처 이름 / 전화번호 / 이메일
- 전화번호(전화·문자)의 번호
- 이메일 주소

이 중 하나라도 기록이 꺼져 있는 채로 QR을 만들면, **QR 이미지 자체도 히스토리에 저장하지 않습니다.** QR 이미지를 저장해두면 누구나 스캔해서 비밀번호 등 민감정보를 알아낼 수 있기 때문입니다. 대신 "🔒" 표시만 남기고, 입력했던 비민감 정보(예: SSID, 회사명 등)만 보여줍니다.

히스토리 항목의 "불러오기"를 누르면 입력 폼에 값이 다시 채워지지만, 비공개로 기록된 항목은 빈칸으로 남아 직접 다시 입력해야 합니다.

히스토리 기능 자체도 설정에서 완전히 켜고 끌 수 있습니다.

## 5. 레이아웃 (반응형)

- **모바일 / 좁은 화면 (900px 미만)**: 본문 → 디자인 설정 → 히스토리 순서로 1열 배치
- **데스크톱 (900px 이상)**: 좌측에 히스토리, 중앙에 QR 생성 본문, 우측에 디자인 설정인 3단 레이아웃. 좌/우 패널은 스크롤해도 따라오는 `sticky` 처리
- 모든 폭/간격은 `dvw`, `dvh`, `%`, `clamp()` 단위를 사용해 화면 크기에 맞춰 자연스럽게 조정됨 (단, 입력칸·버튼 등 좁은 박스 내부의 세부 패딩은 고정 px로 처리해 화면이 넓어져도 패딩이 과도해지지 않도록 함)

## 6. 기술적으로 신경 쓴 부분

- **한글 QR 깨짐 방지**: 내부 의존 라이브러리(`qrcode-generator`)가 문자열을 1글자=1바이트로 가정하고 인코딩하기 때문에, 한글처럼 UTF-8에서 여러 바이트를 쓰는 문자가 그대로 들어가면 깨짐. 생성 전 UTF-8 바이트로 변환한 뒤 1바이트=1문자로 매핑하는 처리를 거쳐서 해결.
- **QR 미리보기 잘림/클리핑 방지**: `qr-code-styling`이 만드는 `<svg>`에는 `viewBox`가 없어 CSS로 크기를 줄이면 잘림이 발생함. 생성 직후 `viewBox`를 직접 채워주고 고정 `width`/`height` 속성을 제거해 비율 유지 반응형 스케일링이 가능하도록 처리.
- **부드러운 아코디언**: 네이티브 `<details>` 대신 직접 만든 컴포넌트를 사용해, 펼침/접힘 시 `height` 트랜지션으로 애니메이션을 주고 테두리가 끊기지 않게 함.

## 7. 파일 구성

```
index.html   QR 종류별 입력 폼, 디자인 설정, 히스토리 UI 마크업
api.js       QR 데이터 생성 로직, 디자인 옵션 처리, 스타일 저장/히스토리(localStorage), 아코디언 동작
app.css      반응형 레이아웃 및 전체 스타일
```

세 파일은 서로 상대 경로(`/api.js`, `/app.css`)로 참조하므로, 같은 폴더에 두고 `index.html`을 웹 서버(또는 그냥 더블클릭)로 열면 됩니다.

## 9. 데이터 보관 위치

이 사이트는 백엔드 서버가 없습니다. 입력한 모든 데이터, 저장한 디자인 스타일, 히스토리 기록은 **사용자의 브라우저 `localStorage`에만 저장**되며, 외부로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 삭제됩니다.
