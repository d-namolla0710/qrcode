# https://qr.minchan.app/

# QR Code 생성기

순수 HTML / CSS / JavaScript로 만든, 브라우저에서 바로 동작하는 무료 QR 코드 생성기입니다.
서버 없이 모든 처리가 브라우저 안에서 이루어지며, [qr-code-styling](https://github.com/kozakdenys/qr-code-styling) 라이브러리(MIT License)를 기반으로 합니다.

> 비개발자도 읽을 수 있는 자세한 설명은 [`PROJECT_OVERVIEW.md`](./PROJECT_OVERVIEW.md)를 참고하세요.

- **현재 버전**: v2.0.0 (2026. 11. 12.)
- **배포**: 자체 배포툴

---

## 1. 한눈에 보는 기능

- **9가지 QR 종류 지원**: URL / 와이파이 / 텍스트 / 이메일 / 전화 / 문자 / 연락처 / 일정 / 위치
- **휴대폰 카메라 자동 인식 형식**으로 데이터 생성 (와이파이 자동 연결, 캘린더 일정 추가 등)
- **실시간 자동 미리보기**: 입력을 멈추면 0.5초 뒤 자동 갱신 (생성 버튼 없음)
- **디자인 커스터마이징**: 빠른 스타일, 색상 견본, 단색/그라데이션, 점·모서리 모양, QR 전체 모양(사각형/원형), 로고 삽입
- **투명 처리**: 배경 없음 + 점/모서리 "투명(구멍 뚫기)"
- **인식 실패 방지**: 명도 대비(WCAG)·조밀도 경고, "인식 잘 되는 QR이에요" 상태 표시
- **내보내기**: PNG / JPEG / WEBP / SVG 다운로드, **클립보드 복사**, **전체화면 보기**
- **스타일 저장/불러오기**, **히스토리**(즐겨찾기·개인정보 보호 설정)
- **다크/라이트 모드**, **반응형 레이아웃** (모바일은 하단 탭바)
- **소개 페이지**: 편집 화면과 같은 디자인, 다크 모드 지원
- **모든 데이터는 로컬에만 저장**: 서버로 전송되지 않고 브라우저 `localStorage`에만 보관

## 2. 페이지 구성

| 경로 | 파일 | 설명 |
| --- | --- | --- |
| `/` | `index.html` | 소개(랜딩) 페이지. QR 종류·기능·개인정보·사용 방법·FAQ |
| `/app` | `app.html` | QR 생성기 본체 (편집 화면) |

- 소개 페이지에서 **"사용해보기"를 한 번 누르면**, 다음 방문부터는 `/`로 들어와도 바로 `/app`으로 이동합니다. (앱 왼쪽 위 로고를 누르면 소개 페이지로 돌아가며 이 설정이 초기화됨)
- 소개 페이지는 Speculation Rules로 `/app`을 미리 렌더링해 전환 속도를 높입니다.
- 소개 페이지의 히어로 QR(`assets/hero-qr.png`)은 실제 QR이며, 찍으면 `https://qr.minchan.app/app`으로 연결됩니다.
- v1.3.0에서 만든 가이드 페이지(`/guides/...`)는 v2.0.0에서 종료했고, 옛 주소는 `_redirects`로 소개 페이지에 301 이동합니다.

## 4. QR 종류별 상세 설명

| 종류 | 휴대폰에서 인식 시 동작 | 입력 항목 | 인코딩 형식 |
| --- | --- | --- | --- |
| URL | 브라우저로 해당 주소 열기 | 주소 (프로토콜 생략 시 `https://` 자동 추가) | 그대로 |
| 와이파이 | 비밀번호 입력 없이 자동 연결 | SSID, 비밀번호, 암호화 방식(WPA/WPA2·WEP·없음), 숨김 네트워크 | `WIFI:` |
| 텍스트 | 텍스트 그대로 표시 | 내용 | 그대로 |
| 이메일 | 메일 앱 실행, 받는사람/제목/내용 자동 입력 | 받는 사람, 제목(선택), 내용(선택) | `mailto:` |
| 전화 | 전화 앱 발신 화면 | 전화번호 | `tel:` |
| 문자 | 문자 앱 작성 화면 | 전화번호, 문자 내용(선택) | `sms:` |
| 연락처 | 연락처 추가 화면 | 이름, 전화번호·이메일·회사(선택) | vCard 3.0 |
| 일정 | 캘린더 일정 추가 | 제목, 시작/종료 일시, 장소·설명(선택) | iCalendar (`VEVENT`) |
| 위치 | 지도 앱에서 좌표 열기 | 위도, 경도 | `geo:` |

- 각 형식의 특수문자는 스펙에 맞게 자동 escape 처리됩니다. (와이파이: `\ ; , : "` / vCard: `\ ; ,` / iCalendar: `\ ; ,` 및 줄바꿈 / 이메일·문자 본문: URL 인코딩)
- 전화번호의 공백과 `-`는 자동 제거됩니다.
- 일정의 종료 일시를 비우면 시작 일시와 같게 처리됩니다.

## 5. 디자인 설정

| 항목 | 조정 가능한 내용 |
| --- | --- |
| 빠른 스타일 | 기본 / 부드럽게 / 도트 / 클래식 — 한 번에 색·점 모양·모서리 모양 적용 |
| 색상 – 점 색 | 견본 6개 + **투명(구멍 뚫기)** + 직접 고르기, **단색/그라데이션** 전환 |
| 색상 – 배경 색 | 견본 5개 + **배경 없음(투명)** + 직접 고르기, **단색/그라데이션** 전환 |
| 그라데이션 편집기 | 미리보기 막대, 시작·끝 색, 선형/원형, 각도(0~360°) |
| 점 모양 | 사각형 / 둥근 사각형 / 매우 둥글게 / 점 / 클래식 / 둥근 클래식 |
| 모서리 모양 | 점 따라가기 / 사각형 / 둥글게 / 원형 |
| QR 모양 | 사각형 / 원형 |
| 고급 설정 | 크기(px)·바깥 여백·오류 복원율(L/M/Q/H), 모서리 사각형·모서리 도트의 색(따라가기/직접 지정/투명)·그라데이션·모양, 미리보기 크기(화면에 맞춤/작게/직접 조절) |

- **색상 선택기**: 브라우저 기본 `<input type="color">` 대신 [Coloris](https://github.com/mdbassit/Coloris)를 사용합니다. 모바일에서도 같은 모양으로 화면 아래쪽에 뜹니다.
- 점을 투명으로 하고 모서리를 "따라가기"로 두면 모서리까지 사라져 인식이 불가능해지므로, 이 경우 모서리는 자동으로 검정색으로 대체됩니다.
- 그라데이션으로 바꾸면 시작 색이 지금 쓰던 단색으로 자동으로 맞춰집니다.
- 입력칸 옆 `↺` 버튼으로 항목별 초기값 되돌리기, "디자인 초기화" 버튼으로 전체 되돌리기가 가능합니다.

## 6. 인식 실패 방지

### 명도 대비 경고
WCAG 상대 휘도 공식으로 배경색과 점·모서리 색상의 대비를 계산합니다. 그라데이션은 모든 색상 조합 중 **가장 낮은 값**을 기준으로 합니다.

| 대비 | 수준 |
| --- | --- |
| 1.5 : 1 미만 | 심각 — 대부분의 기기에서 인식 불가 |
| 1.5 ~ 3 : 1 | 주의 — 일부 기기에서 인식 저하 |

### 조밀도 경고
라이브러리가 계산한 실제 격자 크기(모듈 수)를 읽어 판단합니다.

| 모듈 수 (한 변) | 수준 |
| --- | --- |
| 97 이상 | 매우 촘촘함 |
| 57 ~ 96 | 조금 촘촘함 |

경고가 없으면 미리보기 아래에 **"인식 잘 되는 QR이에요 · 대비 N:1"** 상태 칩이 표시되고, 배경이 투명이면 "붙일 곳의 배경과 대비를 확인해 주세요" 안내가 표시됩니다.

## 7. 내보내기 · 복사 · 전체화면

| 기능 | 설명 |
| --- | --- |
| 다운로드 | 상단 "다운로드" → 팝오버에서 PNG / JPEG / WEBP / SVG 선택. 형식별 설명 표시, JPEG + 투명 사용 시 안내 |
| 복사 | 상단 "복사" → 현재 QR을 PNG로 클립보드에 복사 (구멍 뚫기 반영). **https 또는 localhost에서만 동작** (브라우저 보안 규칙) |
| 전체화면 | 미리보기 오른쪽 위 "전체화면" → 화면 짧은 쪽 기준으로 최대 크기, 배경은 QR 배경색과 동일. 화면을 누르거나 ESC로 닫기 |

- 구멍 뚫기를 쓴 QR은 라이브러리 기본 `download()`가 구멍을 반영하지 못하므로, 화면에 그려진 SVG를 직접 저장/변환합니다.

## 8. 히스토리(기록) & 개인정보 보호

입력을 멈추고 2초가 지나면 종류, 입력값, 디자인 설정이 자동으로 기록됩니다.

- **즐겨찾기**: 즐겨찾기한 항목은 목록 상단에 고정되고, 자동 삭제 대상에서 제외됩니다.
- **최대 개수**(기본 50개): 초과 시 즐겨찾기가 아닌 오래된 항목부터 자동 삭제
- **페이지 나누기**: 한 페이지당 표시 개수 설정 가능 (기본 5개)
- 기록 기능 자체를 끌 수 있습니다.

**개인정보 보호를 위해 아래 항목은 기본적으로 기록되지 않습니다** (설정에서 개별적으로 켤 수 있음):

- 와이파이 비밀번호
- 연락처 이름 / 전화번호 / 이메일
- 전화번호(전화·문자)의 번호
- 이메일 주소

이 중 하나라도 기록이 꺼진 상태로 QR을 만들면, **QR 데이터와 썸네일 자체도 저장하지 않습니다.** QR 이미지만 있어도 스캔으로 민감정보를 알아낼 수 있기 때문입니다. 대신 🔒 표시와 비민감 정보(SSID, 회사명 등)만 남깁니다.

## 10. 기술적으로 신경 쓴 부분

- **한글 QR 깨짐 방지**: 내부 의존 라이브러리(`qrcode-generator`)가 문자열을 1글자=1바이트로 가정하므로, 생성 전 UTF-8 바이트로 변환한 뒤 1바이트=1문자로 매핑해서 전달합니다.
- **SVG 잘림 방지**: `qr-code-styling`이 만드는 `<svg>`에는 `viewBox`가 없어 CSS로 줄이면 잘립니다. 생성 직후 `viewBox`를 채우고 고정 `width`/`height`를 제거합니다.
- **구멍 뚫기(hole punch)**: 라이브러리가 SVG 안에 만들어 둔 점/모서리별 `clipPath`를 재사용해 배경에 `mask`를 씌우고, 원래 점을 칠하던 요소는 제거합니다.
- **깜빡임 없는 미리보기**: 새 QR을 임시 요소에 완성한 뒤 `replaceChildren()`으로 한 번에 교체합니다.
- **디바운스**: 미리보기 0.5초, 기록 2초. 기록을 불러온 직후에는 중복 기록을 막기 위해 잠시 기록을 멈춥니다.
- **새 UI는 기존 입력칸 위에 얹는 구조**: 타일·견본·탭 버튼은 숨겨진 기존 `select`/`input` 값을 바꾸고 `change` 이벤트를 보내는 방식이라, 미리보기·기록·스타일 저장 로직을 그대로 재사용합니다.
- **미리보기 "화면에 맞춤"**: 미리보기 영역에 잘리지 않고 들어가는 가장 큰 정사각형 크기를 계산해서 적용합니다.
- **하위 호환**: `colorMode`가 없던 이전 버전의 프리셋/기록은 "직접 지정"으로 간주해 저장된 색을 그대로 보존합니다.

```
_redirects             종료된 가이드 페이지 주소 → 소개 페이지 301 이동
robots.txt             크롤러 규칙 (AI 학습 크롤러 차단)
sitemap.xml            사이트맵
wrangler.jsonc         Cloudflare 배포 설정
```

## 12. 로컬에서 실행하기

파일들이 `/editor.css`, `/app.js`처럼 **루트 기준 절대 경로**로 서로를 참조하므로, HTML 파일을 더블클릭하지 말고 로컬 서버로 여는 것을 권장합니다.

```powershell
# 실행 위치: 노트북 PowerShell, qrcode 폴더 안
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/app.html` 을 엽니다.

```powershell
# 실행 위치: 노트북 PowerShell, qrcode 폴더 안
npx wrangler dev
```

> 같은 공유기 안의 다른 기기에서 `http://192.168.x.x:포트`로 열면 **복사 기능은 동작하지 않습니다.** 브라우저가 https나 localhost가 아닌 주소에서는 클립보드 쓰기를 막기 때문입니다.

## 15. 데이터 보관 위치

이 사이트에는 백엔드 서버가 없습니다. 입력한 데이터, 저장한 스타일, 기록, 화면 설정은 모두 **사용자의 브라우저 `localStorage`에만 저장**되며 외부로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 삭제됩니다.

| 키 | 내용 |
| --- | --- |
| `qrgen-theme` | 다크/라이트 모드 |
| `qrgen-visited` | 소개 페이지 건너뛰기 플래그 |
| `qrgen-last-type` | 마지막 QR 종류 |
| `qrgen-editor-tab` | 마지막으로 연 편집 메뉴 |
| `qrgen-style-presets` | 저장한 스타일 |
| `qrgen-history` | 기록 목록 |
| `qrgen-history-enabled` | 기록 사용 여부 |
| `qrgen-history-privacy` | 민감정보 항목별 기록 허용 |
| `qrgen-history-max` | 기록 최대 개수 |
| `qrgen-history-page-size` | 페이지당 표시 개수 |
| `qrgen-browser-warning-dismissed` | 브라우저 안내 다시 보지 않기 |
| `qr-preview-view-mode-v1` | 미리보기 크기 방식 |
| `qr-preview-manual-size-v1` | "직접 조절" 모드 크기 |
