해결 방법
  • 배경은 더 밝게, 점·모서리는 더 어둡게 바꿔 보세요.
  • 반대로 어두운 배경에 밝은 점도 가능해요.
  • 그라데이션을 쓴다면 양 끝 색 모두 배경과 차이가 충분해야 해요.
해결 방법
  • 담는 내용(특히 한글)을 줄여 보세요.
  • 오류 복원율을 L 또는 M으로 낮춰 보세요.
  • 로고를 빼거나 더 작게 해 보세요.
  • 인쇄하거나 화면에 띄울 때 더 크게 보여주세요.

v. 2.0.0 2026. 11. 12.

편집 화면 전면 리디자인

  • 왼쪽 아이콘 메뉴(내용·디자인·로고·내 스타일·기록) + 큰 미리보기로 화면 구성 변경
  • QR 종류 선택을 드롭다운에서 아이콘 타일로 변경
  • 디자인 설정을 아코디언에서 빠른 스타일·색상 견본·모양 타일로 개편, 세부 항목은 "고급 설정"으로 정리
  • 점·배경 색에 단색/그라데이션 전환 추가, 그라데이션 편집기(시작·끝 색, 선형/원형, 각도) 추가
  • 점 "투명(구멍 뚫기)"을 색상 견본에서 바로 고를 수 있도록 변경
  • QR 전체 모양(사각형/원형)을 고급 설정 밖으로 이동
  • 브라우저 기본 색상 선택기 대신 Coloris 색상 선택기 적용 (모바일에서도 같은 모양)
  • 미리보기 배경을 체크무늬로 고정하고, 미리보기 크기를 화면에 맞게 자동 조절
  • "인식 잘 되는 QR이에요" 상태 표시 추가, 대비·조밀도 경고를 미리보기 아래 칩으로 변경

새 기능

  • QR 전체화면 보기 추가 (화면에 꽉 차게 띄워서 바로 스캔)
  • QR 이미지 클립보드 복사 버튼 추가
  • 다운로드 창을 상단 팝오버로 변경하고 형식별 설명 추가
  • 알림·확인 창을 브라우저 기본 창 대신 사이트 디자인에 맞춘 모달로 변경
  • 마지막으로 열었던 편집 메뉴를 다음 방문 시 기억

디자인 · 기타

  • 포인트 색상(파랑)과 글꼴(영문·숫자 SUIT, 한글 나눔스퀘어) 변경
  • 모바일 하단 탭바 레이아웃 적용
  • 파비콘 교체
  • 소개 페이지를 새 디자인으로 처음부터 다시 작성
  • 링크 공유 미리보기(Open Graph) 이미지 교체
  • 가이드 페이지 종료 (기존 주소는 소개 페이지로 이동)
  • 안내 문구를 더 쉬운 말투로 정리

버그 수정

  • 기록 탭에서 "페이지당 개수"를 5 이상으로 설정하면 값이 이상하게 바뀌던 버그 수정
  • 패치노트 안 가이드 페이지 링크가 열리지 않던 버그 수정
